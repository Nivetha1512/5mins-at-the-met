# Bundled Met Open Access paintings

Agent 3 owns this folder.

Download ~8–12 CC0 paintings from [The Met Open Access](https://metmuseum.github.io/) (collection object pages / Open Access images). Write `artworks.json` matching the `Artwork` type in `src/shared/types.ts`.

Every entry **must** include `description` (1–3 sentences: historical context or a fun fact). Break-complete UI shows title, artist, year, and description.

Do not fetch these files at runtime.
